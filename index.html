Como funciona

Quem cria a sala é o anfitrião: a partida roda no aparelho dele. Só jogadores de verdade, sem bots, de 2 a 8 por sala. A zona fecha mais rápido para vocês se encontrarem.

Aqui no Claude: seus amigos precisam abrir este mesmo jogo com acesso de Colaborador (menu Compartilhar).
Na versão do GitHub Pages: qualquer pessoa com o link entra usando o código da sala.

Para jogar sozinho contra bots, sem internet, use a aba Contra bots.
